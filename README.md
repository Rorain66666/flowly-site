# Flowly · AI 与效率工具导航

这是一个无需后端、可直接部署到公网的静态网站首版。页面包含：

- 按场景浏览：写作、设计、学习、会议、自动化、个人成长
- 工具搜索与分类筛选
- 收藏工具（保存在访客自己的浏览器 `localStorage` 中）
- 深色模式
- 外部工具直达链接
- 订阅表单交互（首版仅展示成功提示，接入邮件服务后即可收集地址）

## 为什么选这个方向

本方案依据公开网站长期访问结构与近年增长方向做了取舍：搜索/信息获取、AI 助手、内容创作和生产力工具是跨人群的高频需求；“目录 + 场景工作流”比单一工具落地更快，也便于通过 SEO、分享卡片和联盟链接持续扩展。

首版刻意保持纯静态，任何人都能打开，部署成本低。后续可以按优先级增加：

1. 工具详情页与真实评测
2. 投稿、登录和云端收藏
3. 邮件订阅与每周精选自动发送
4. 联盟链接、赞助位和团队版工作流

## 发布到公网

### Vercel（最快）

1. 把 `flowly-site` 文件夹上传到 GitHub。
2. 在 [Vercel](https://vercel.com/) 选择 **Add New → Project**，导入这个仓库。
3. Framework Preset 选择 **Other**，点击 Deploy。
4. Vercel 会生成一个 `*.vercel.app` 网址，复制给任何人即可访问。

### Netlify

在 [Netlify](https://app.netlify.com/drop) 直接把 `flowly-site` 文件夹拖入页面，就会得到公开网址。

### GitHub Pages

把文件放在仓库根目录（或 `docs` 目录），在仓库的 **Settings → Pages** 选择对应分支并保存即可。

## 本地预览

直接双击 `index.html` 即可预览；也可以在该文件夹运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
